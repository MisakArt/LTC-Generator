About

What is timecode?

Timecode labels every video or audio frame with a unique address in the form HH:MM:SS:FF (hours, minutes, seconds, frames). Cameras, recorders, consoles and playback systems that follow the same timecode can be synchronised and lined up exactly. LTC (Linear Timecode, SMPTE 12M) carries that address as an audio signal (biphase-mark, 80 bits per frame), so it can be sent over a normal audio cable or recorded on an audio track.

Features

  • Live LTC output in the browser: play, stop and reset, with keyboard shortcuts (Space, R).
  • Frame rates 23.976, 24, 25, 29.97 DF, 29.97 NDF and 30 fps. Drop frame is shown with ;.
  • Any start time, strict SMPTE 12M frame layout (user bits and flags are zero).
  • 25 µs rise-time edge shaping (SMPTE) or a hard square wave.
  • Output level control and a waveform view of one frame.
  • Output device selection (Chromium browsers only).
  • WAV export: mono, 44.1 / 48 / 96 kHz, 16-bit, 24-bit or 32-bit float. Length 1–240 minutes (or 1–14400 seconds), limited by the 4 GB WAV size limit. Live file size, end timecode, frame count, samples per frame and bit rate.

Every device in the chain must use the same rate. 30 fps against a 29.97 source drifts about one frame every 33 seconds.

Drop frame in short

Only the numbering is corrected; no frames are removed. Labels 00 and 01 are skipped at the start of each minute, except every tenth minute. Drop frame is written with a semicolon, e.g. 01:00:00;02. One hour = 107,892 frames.

Using it on a show
  • Use a dedicated output for LTC.
  • No EQ, compression, limiting or gate on the LTC path.
  • Never send it over Bluetooth or through lossy codecs.
  • Start around -6 dBFS and adjust to the receiver.
  • Give the receiver a few seconds of timecode before the first cue.
